# ShopSphere Campaign Response Analytics

## Project Overview
ShopSphere Campaign Response Analytics is a machine learning project that analyzes customer, marketing campaign, website activity, and customer service data to understand purchase behavior and predict which customers are more likely to respond to a campaign.

## 🚀Live Demo: Open ShopSphere App



## Problem Statement
Marketing teams need to identify customers who are more likely to purchase so they can plan targeted campaigns and use marketing budgets more effectively.

## Tech Stack
- Python, Pandas, NumPy
- Scikit-learn, XGBoost
- SQL (if used in the project workflow)
- Streamlit
- Large Language Model (LLM) for business explanations and marketing recommendations

## Key Features
- Data cleaning and feature engineering
- Comparison of machine learning models
- Campaign and customer KPI dashboards
- Customer purchase-response prediction
- Feature importance analysis
- Business metrics and marketing insights
- LLM-based Marketing Assistant

## Machine Learning
Several classification models were evaluated, including Logistic Regression, Decision Tree, Random Forest, and XGBoost.

## How to Run
1. Clone or download this repository.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Run the application using `streamlit run app.py`.

## Note
Model performance and business metrics are based on the project's dataset and evaluation setup. They should not be interpreted as guaranteed real-world marketing results.
